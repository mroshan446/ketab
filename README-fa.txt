نصب «کتاب من» روی گوشی بدون APK و بدون Android Studio
====================================================
این پوشه یک «وب‌اپ» است. یک‌بار آن را روی اینترنت می‌گذارید و بعد هر گوشی آن را مثل یک برنامه نصب می‌کند.
بعد از نصب، برنامه بدون اینترنت کار می‌کند و اطلاعات روی همان گوشی می‌ماند.

بخش اول: گذاشتن فایل‌ها روی اینترنت (یک‌بار، روی کامپیوتر، با فیلترشکن روشن)
-------------------------------------------------------------------------
1) به سایت github.com بروید و ثبت‌نام کنید (ایمیل، نام کاربری و رمز).
2) بالا سمت راست روی + و بعد New repository بزنید.
3) در Repository name بنویسید: ketab
   گزینهٔ Public را بزنید. پایین روی Create repository بزنید.
4) در صفحه‌ای که باز می‌شود، روی لینک  uploading an existing file  بزنید.
5) فایل‌های این پوشه را همه با هم بکشید و داخل صفحه رها کنید:
      index.html ، manifest.webmanifest ، sw.js ، icon-192.png ، icon-512.png
   (پوشه را نکشید؛ خود فایل‌ها را بکشید.) صبر کنید همه بارگذاری شوند.
6) پایین صفحه روی Commit changes بزنید.
7) بالای صفحه روی Settings بزنید، از ستون چپ Pages را انتخاب کنید.
8) در Branch گزینهٔ main را انتخاب کنید، کنارش / (root) بماند و Save بزنید.
9) یک تا دو دقیقه صبر کنید و صفحه را تازه کنید. بالای صفحه آدرس برنامه نوشته می‌شود، مثل:
      https://نام-کاربری-شما.github.io/ketab/
   این آدرس را یادداشت کنید.

بخش دوم: نصب روی هر گوشی
------------------------
1) در گوشی مرورگر Chrome را باز کنید و آدرس بالا را بزنید (اگر باز نشد فیلترشکن روشن کنید).
2) بار اول از شما نام کاربری گوشی را می‌پرسد (برای هر گوشی یک نام متفاوت).
3) در Chrome روی سه نقطهٔ بالا بزنید و Install app یا Add to Home screen را انتخاب کنید و تأیید کنید.
4) آیکون «کتاب من» روی صفحهٔ گوشی ظاهر می‌شود. از همان‌جا باز کنید.
از این به بعد برای باز کردن برنامه به اینترنت یا فیلترشکن نیازی نیست.

هماهنگ‌سازی چند گوشی
--------------------
همان روش قبل: در تنظیمات و پشتیبان، «ساخت و ارسال فایل پشتیبان» را بزنید، فایل را برای گوشی دیگر بفرستید و آنجا «افزودن فایل پشتیبان گوشی دیگر» را بزنید.

نکته‌های مهم
------------
- اطلاعات فقط روی همان گوشی است. اگر اطلاعات سایت‌های Chrome پاک شود یا برنامه حذف شود، اطلاعات می‌رود. مرتب پشتیبان بگیرید.
- دکمهٔ پیامک برنامهٔ پیامک خود گوشی را با متن آماده باز می‌کند.
- اگر خواستید برنامه به‌روز شود، فایل جدید را در همان مخزن جایگزین کنید.
